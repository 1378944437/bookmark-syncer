## 3. 已保留的后续工具

[verify-service.cjs](../scripts/verify-service.cjs) 可在以后通过实际扩展后台执行只读连接检查，使用 Node 24、本机已有 Playwright 与 Edge：

```powershell
$env:MARKSYNC_PLAYWRIGHT = '<已安装的 playwright 模块绝对路径>'
node scripts/verify-service.cjs --self-test
# 后续实际使用时，可用 --config <本机配置文件路径> 代替 --self-test
```

该工具只发起连接测试，不证明写入权限、完整同步或真实服务端并发语义。自检覆盖 WebDAV/Gist 的成功、401、503、仅出现 GET/PROPFIND 请求、凭据不写入扩展配置及错误脱敏。输出只保留结果分类和可识别的 HTTP 状态码，不写入服务器地址、账号、令牌或原始错误正文。

`*.service.local.json` 已加入忽略规则。真实账号配置尚未提供，也未执行真实服务检查；无需为完成本轮补充这些信息。
