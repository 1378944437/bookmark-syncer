# MarkSync 1.5.4：设置页滚动与手机主题适配

> 2026-09-15。本地修复与验证完成；按用户授权提交、推送，并由现有 GitHub Actions 执行远端测试与构建。远端运行结果以 Actions 为准。

## 问题与修复

- 云存储子页父容器使用 `overflow-hidden`，WebDAV 内层又按自身内容增长，导致内容溢出后没有可用滚动通道。旧 1.5.3 在 360×560 视口滚到底后，测试按钮仍位于 y=613～653，超出可视范围。
- 将云存储子页作为滚动容器，WebDAV 表单按内容自然排布，Gist 共用这一滚动通道。弹窗高度上限跟随动态视口，保留底部安全区间距，导航不参与高度压缩。
- 原主题代码只修改第一条带系统主题条件的 `theme-color`，应用主题与系统主题不同时可能失效。现在使用一条无条件主题色，取实际页面背景，并同步 CSS `color-scheme` 与对应元数据；两平台初始页面与默认深色主题一致。
- 根版本更新为 1.5.4。同步、存储、加密业务逻辑未修改。
