# 独立大屏控制台审查与后续优化

## 本轮已修复

- 手机仪表盘中“查看本地快照”使用弹窗时代的负边距和强制满高，容易与后续“当前连接”卡片发生视觉重叠。移动端改为自然高度，快照入口恢复为独立卡片。
- 桌面端仍保留同步视图的完整操作、抽屉、冲突确认和恢复流程；本次只调整布局，不改变同步逻辑。

## 发现的问题

| 优先级 | 位置 | 问题 | 建议 |
| --- | --- | --- | --- |
| P1 | `SyncView` / `SyncFooter` | 弹窗样式（负边距、底部贴边、`h-full`）复用到大屏卡片，移动端层级容易相互覆盖。 | 已增加控制台专用容器类；后续可将 footer 作为显式布局插槽传入。 |
| P1 | `FullTabSnapshots.tsx` | 273 行同时处理加载、搜索、创建、删除、恢复、卡片渲染和英文标签转换。 | 拆成 `SnapshotToolbar`、`SnapshotCard`、`SnapshotGrid`，状态处理留在页面层。 |
| P2 | `SyncActivityPanel` | 摘要卡片和完整活动页共用同一组件，只通过高度参数区分，信息密度和空状态不够明确。 | 增加 `mode="summary" | "full"`，摘要只展示最近记录和关键指标。 |
| P2 | 全局控制台 CSS | 控制台样式集中在 `index.css` 的长行规则，组件结构与视觉规则分离，修改成本较高。 | 保留设计 token，将控制台规则迁移到独立 `fulltab.css` 或组件级样式层。 |
| P2 | `FullTabDashboard` | 连接详情和同步操作都直接读取 storage，页面刷新时状态加载时序不统一。 | 提取 `useConsoleSummary`，统一设备、加密、自动同步和连接状态快照。 |
| P3 | 导航 | 当前导航状态只保存在 React state，刷新后回到仪表盘。 | 后续可使用 URL hash 保存当前面板，支持浏览器前进/后退和深链接。 |
| P3 | 快照搜索 | 日期过滤依赖本地化字符串，跨语言和跨时区检索不稳定。 | 统一格式化日期字段，并保留原始时间戳用于查询。 |

## 验证范围

- Chrome / Edge：类型检查与构建通过。
- Firefox：类型检查与构建通过。
- 独立控制台：中文默认语言下导航、仪表盘和活动页在隔离 Edge 中打开，无运行时错误。
- 手机快照入口修复：同步视图移动端自然高度规则已构建；真实 Android 浏览器仍需实际使用确认。
